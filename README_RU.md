# Schoolly — GitHub Pages + уведомления на телефон

В этой сборке **нет Render**. Сайт размещается на GitHub Pages, а GitHub Actions примерно раз в 5 минут проверяет `tasks.json` и отправляет уведомления через бесплатный сервис ntfy. Уведомления приходят через приложение ntfy, даже когда Schoolly закрыт.

## 1. Создай приватный репозиторий

1. На GitHub создай репозиторий `schoolly` (лучше Private).
2. Загрузи в него содержимое архива целиком: папки `.github`, `public`, `scripts`, а также `tasks.json` и `notified.json`.
3. Ветка должна называться `main`.

## 2. Включи сайт

1. Открой репозиторий → **Settings → Pages**.
2. В разделе Build and deployment выбери **GitHub Actions**.
3. Открой вкладку **Actions** и запусти `Deploy Schoolly to GitHub Pages` (или сделай любой commit в `public/`).
4. GitHub покажет адрес сайта вида `https://ТВОЙ-АККАУНТ.github.io/schoolly/`.

## 3. Настрой уведомления на телефоне

1. Установи официальное приложение **ntfy** из магазина приложений.
2. Придумай длинное случайное название темы (topic), например набор из 25–35 случайных букв и цифр. Не используй имя, дату рождения или название школы. Не публикуй тему и не отправляй её другим людям: любой, кто знает её, может подписаться на уведомления.
3. В приложении ntfy подпишись на сервер `https://ntfy.sh` и на эту тему.
4. В GitHub открой **Settings → Secrets and variables → Actions → New repository secret**.
5. Имя секрета: `NTFY_TOPIC`. Значение: то же название темы. Сохрани.
6. Открой **Actions → Schoolly deadline notifications → Run workflow**, чтобы проверить настройку. Для теста добавь тестовое задание в `tasks.json` с дедлайном примерно через 10–20 минут и напоминанием `"1min"`.

## 4. Как передавать задания из Schoolly в GitHub

Это важное ограничение: задания исходного Schoolly хранятся в `localStorage` только в браузере. GitHub Actions не может прочитать данные из телефона сам.

1. В Schoolly открой **Настройки → Экспортировать задания**.
2. Скачанный JSON-файл открой как текст.
3. В репозитории GitHub открой `tasks.json` → Edit (карандаш), замени содержимое на экспортированный JSON и нажми **Commit changes**.
4. После каждого изменения списка заданий повторяй экспорт и обновление `tasks.json`.

Формат `tasks.json` — массив заданий, такой же, как экспортирует Schoolly. Не удаляй квадратные скобки `[` и `]`.

## Важные ограничения

- GitHub Actions запускается по расписанию **примерно раз в 5 минут**, но GitHub может задерживать запуск. Это не гарантия доставки точно в минуту; напоминание за 1 минуту тоже может прийти с опозданием.
- Временная зона настроена на `Europe/Berlin`.
- Телефон должен иметь интернет и разрешать уведомления приложению ntfy.
- Публичный ntfy topic работает как секретная ссылка: не публикуй его. Не добавляй пароли или личные данные в задания.
- Этот вариант бесплатный на обычном объёме GitHub Actions и ntfy, но лимиты и условия сервисов могут меняться. Не подключай платные планы и не вводи платёжные данные.
- **Автоматической синхронизации задач пока нет**: после изменений нужно снова экспортировать `tasks.json` и обновить файл в GitHub. Без отдельного защищённого хранилища GitHub Actions не видит `localStorage` сайта.
